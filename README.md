Les émulateurs proposés par le site permettent de :
- Modifier les commandes (y compris si vous avez une manette)
- Sauvegarder / Charger sa partie à n'importe quel moment.
- Pause / Plein écran / Accéléré et ralenti
- Mettre des filtres pour avoir une image ou bien plus lisse ou au contraire une image de télévision CRT (tubes cathodiques)
- Des cheats (y a pas de jeux en ligne pour le moment donc bon... faites comme bon vous semble)

Notez que certaines consoles / jeux ou même des filtres peuvent nécessiter un ordinateur costaud. (NES, GameBoy, Snes... sans problème. N64 ou avec des filtres CRT par contre oui).
