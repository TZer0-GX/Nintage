### Nin-tage
Projet universitaire | Site concernant les consoles NES (1983) et GameBoy (1989) de Nintendo et de leur histoire.

## Commandes en jeu
 > Manette < | > Clavier <

|     A      =     X      |
|     B      =     Z      |
|    Start   =   Entrée   |
|   Select   =    Space   |
|     Up     = Touche HAUT|
|    Down    = Touche BAS |
|    Left    = Touche LEFT|
|    Right   =Touche RIGHT|
